# Graph Schema v0 — Warden + Transformer

**Source of truth.** Kùzu DDL is generated from this document (not hand-edited).  
**Implementation:** `@mendpoint/graph-learn` (SQLite property graph today; Kùzu escape hatch).  
**Naming:** `PascalCase` node labels · `SCREAMING_SNAKE` edge types · `snake_case` properties.

Grounding: deterministic multi-hop first ([arXiv 2601.09842](https://arxiv.org/abs/2601.09842)), temporal edges ([GitTemporalAI](https://users.cs.fiu.edu/~dluo/papers/GitTemporalAI.pdf)), outcome edges as compounding substrate.

---

## Design goals

1. **One schema, both agents** — Warden types extend base; Transformer types extend base; shared queries work.
2. **Structural queries first** — embeddings second (nullable `embedding` stub).
3. **Temporal edges first-class** — every mutable edge has `valid_from` / `valid_to` (NULL = current).
4. **Outcome edges are a family** — not properties on structural edges.
5. **No LLM-inferred “conceptually related” edges** in v0.

## Base nodes (shared)

### Structural
- **Repository** — name, url, primary_language, default_branch  
- **Commit** — sha, author, timestamp, message  
- **PullRequest** — number, title, state, opened_at, merged_at, reverted_at  
- **File** — path, language, loc, hash  
- **Module** — qualified_name, module_kind (package/namespace)  
- **Symbol** — qualified_name, symbol_kind, signature, visibility  
- **Test** — qualified_name, framework, test_kind  

### People / process
- **Author**, **Reviewer**, **Agent**, **Run**, **Plan**

### Semantic
- **Pattern** — name, description, source_lang, target_lang, success_rate, sample_count  
- **Invariant** — expression, inv_kind (pre/post/inv), scope_symbol_id  
- **Trace** — trace_kind, captured_at, blob_ref  

## Warden nodes
**Service**, **Endpoint**, **Schema**, **Field**, **AuthScope**, **ErrorType**, **Consumer**, **SLO**, **RateLimit**, **Deployment**, **Provider** (alias/service parent), **Change**, **Surface**

## Transformer nodes
**LegacySystem**, **TargetSystem**, **Campaign**, **MigrationUnit**, **BSGNode**, **DataStore**, **BusinessRule**, **DialectFeature**

Spines:
- Warden: `Service → Endpoint → Field → Consumer`  
- Transformer: `Campaign → MigrationUnit → BSGNode → Symbol`  
Shared: `Symbol`, `File`, `Test`, `Pattern`, `Invariant`, `Trace`

## Edge families

### Structural
`CONTAINS`, `DEFINES`, `DECLARES`, `CALLS`, `IMPORTS`, `READS_FIELD`, `WRITES_FIELD`, `READS_TABLE`, `WRITES_TABLE`, `RETURNS`, `INHERITS_FROM`, `IMPLEMENTS`, `TESTS`

### Spec / contract (Warden)
`EXPOSES`, `HAS_SCHEMA`, `HAS_FIELD`, `REQUIRES_SCOPE`, `RETURNS_ERROR`, `RATE_LIMITED_BY`, `GOVERNED_BY_SLO`, `IMPLEMENTED_BY`, `CONSUMES`, `DEPRECATES`, `VERSIONS`, `MONITORS`, `BREAKS`, `IMPACTS`, `HAS_ENDPOINT`

### Migration (Transformer)
`IN_CAMPAIGN`, `MIGRATES`, `DEPENDS_ON`, `EXTRACTED_FROM`, `REALIZED_BY`, `PRESERVES_INVARIANT`, `ENCODES_RULE`, `USES_DIALECT`, `MAPS_TO_TARGET`, `MIGRATED_FROM`

### Temporal / process
`AUTHORED`, `MODIFIES`, `INCLUDES_COMMIT`, `TOUCHES`, `REVIEWED`, `PRODUCED`, `EXECUTED_PLAN`, `RELATED`

### Outcome / learning
`SUCCEEDED_ON`, `BROKE`, `REQUIRED_HUMAN_FIX`, `REVERTED_FOR`, `MATCHED_PATTERN`, `PROMOTED`, `TRAINED_ON`,  
plus aliases written by pipeline: `OUTCOME_MERGED`, `OUTCOME_CLOSED`, `OUTCOME_BROKE`, `OUTCOME_WAIVED`

## Fast query shapes (v0)

1. Blast radius / consumers of field  
2. Historical BROKE patterns for endpoint  
3. Topo-next MigrationUnit  
4. Invariants for symbol via BSG  
5. Pattern lookup success_rate  
6. Time-travel CALLS at timestamp t  
7. Time-travel MODIFIES/TOUCHES (git temporal backfill)  
8. Latency stats (p50/p99 SLO samples)

See `@mendpoint/graph-learn` query ops: `who_consumes_*`, `blast_radius`, `callers`, `path`, `depends_on_path`, `pattern_success_rates`, `time_travel_calls`, `time_travel_modifies`, `latency_stats`, `migration_ready_units`.

**Git temporal:** `backfillGitTemporal(db, { repoPath, months: 12 })` → Repository/Commit/Author/File + AUTHORED/MODIFIES/TOUCHES/INCLUDES_COMMIT with `valid_from`/`valid_to`.

## Indexes (SQLite / future Kùzu)

- nodes: kind, repo_id, (kind+label)  
- edges: source, target, kind, valid_from  
- Hot props in props_json for v0; promote columns when needed  

## Evolution rules

- Add node/edge/property = minor, backfill lazy  
- Rename/remove = major, two-version deprecation  
- Every change: 20-query benchmark must still pass  

## Non-goals v0

No ontology over-merge, no CRDTs, no LLM-inferred edges, no GNN features populated, no user-facing schema UI.

## Kùzu escape hatch

```text
CREATE NODE TABLE Node(id STRING, kind STRING, label STRING, repo_id STRING,
  first_seen STRING, last_seen STRING, props STRING, PRIMARY KEY(id));
CREATE REL TABLE Edge(FROM Node TO Node, kind STRING, valid_from STRING,
  valid_to STRING, source_system STRING, confidence DOUBLE, label DOUBLE, props STRING);
```
