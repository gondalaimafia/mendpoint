# Node runtime 20 to 22 consumer fixtures

Synthetic before/after consumer pins for the `node-runtime-20-to-22` provider
recipe (see `docs/TRANSFORMER_RUNTIME_RECIPES.md`). No real customer code.

- `before/` — a repository pinned to Node 20 on the recipe's supported surface:
  `package.json` declares `engines.node` at a recognized Node 20 selector, and
  `.nvmrc`, `.node-version`, and the `Dockerfile` base image all read major 20.
  Analysis classifies this as `applicable`.
- `after/` — the exact deterministic output of applying the recipe to `before/`.
  `engines.node` becomes `>=22 <23`, `.nvmrc`/`.node-version` read `22`, and the
  `Dockerfile` base image becomes `node:22-alpine`. Regenerated by the transform
  and asserted byte-for-byte in
  `packages/transformer/src/recipe-node-runtime.test.ts`, so it never drifts.
- `out-of-scope/` — a repository whose `Dockerfile` base image is pinned to
  `node:21`, a major the recipe does not recognize as a Node 20 pin. Analysis
  classifies this as `unsupported` (reason
  `recipe_precondition_failed:Dockerfile:node_major`) and the recipe abstains
  rather than rewriting an unexpected pin.

Files are pinned to LF (`.gitattributes`) so the content-addressed digests are
stable across platforms.
