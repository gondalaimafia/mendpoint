# googleapis v25 to v26 consumer fixtures

Synthetic before/after consumer sources for the `googleapis-v25-to-v26` provider
recipe (see `docs/TRANSFORMER_SDK_RECIPES.md`). No real customer code.

- `before/` — a v25 consumer on the recipe's supported surface: `src/client.js`
  imports the library with the default form `const google = require("googleapis")`,
  plus a `package.json` that declares the `googleapis` v25 dependency. Analysis
  classifies this as `applicable`.
- `after/` — the exact deterministic output of applying the recipe to `before/`.
  The default import is rewritten to the named form
  `const { google } = require("googleapis")` (the v26.0.0 breaking change) and
  the `googleapis` dependency is bumped to v26. Consumer `google.*` usage is byte
  identical. Regenerated by the transform and asserted byte-for-byte in
  `packages/transformer/src/recipe-googleapis.test.ts`, so it never drifts.
- `out-of-scope/` — a consumer that uses a namespace import
  (`import * as googleapis from "googleapis"`), outside the recipe's
  default-import surface. Analysis classifies this as `unsupported` and the
  recipe abstains.

Files are pinned to LF (`.gitattributes`) so the content-addressed digests are
stable across platforms.
