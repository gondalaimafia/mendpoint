# AWS SDK for JavaScript v2 to v3 consumer fixtures

Synthetic before/after consumer sources for the `aws-sdk-js-v2-to-v3` provider
recipe (see `docs/TRANSFORMER_SDK_RECIPES.md`). No real customer code.

- `before/` — a v2 consumer on the recipe's supported surface: an ESM S3 module
  (`src/s3.js`) and a CommonJS DynamoDB DocumentClient module (`src/dynamo.js`),
  plus a `package.json` that declares the `aws-sdk` v2 dependency. Analysis
  classifies this as `applicable`.
- `after/` — the exact deterministic output of applying the recipe to `before/`.
  Regenerated by the transform and asserted byte-for-byte in
  `packages/transformer/src/recipe-aws-sdk.test.ts`, so it never drifts.
- `out-of-scope/` — a v2 consumer that uses an unsupported service (`AWS.SQS`).
  Analysis classifies this as `unsupported` and the recipe abstains rather than
  producing a wrong edit.

Files are pinned to LF (`.gitattributes`) so the content-addressed digests are
stable across platforms.
