# Stripe Node v10 to v11 consumer fixtures

Synthetic before/after consumer sources for the `stripe-node-v10-to-v11`
provider recipe (see `docs/TRANSFORMER_SDK_RECIPES.md`). No real customer code.

- `before/` — a v10 consumer on the recipe's supported surface: `src/payments.js`
  constructs a Stripe client and configures it with the removed setter methods
  (`setApiVersion`, `setTimeout`, `setMaxNetworkRetries`), plus a `package.json`
  that declares the `stripe` v10 dependency. Analysis classifies this as
  `applicable`.
- `after/` — the exact deterministic output of applying the recipe to `before/`.
  The setter calls are folded into the constructor options object and the
  `stripe` dependency is bumped to v11. Regenerated by the transform and asserted
  byte-for-byte in `packages/transformer/src/recipe-stripe-node.test.ts`, so it
  never drifts.
- `out-of-scope/` — a v10 consumer that calls `setApiKey`, which rewrites the
  constructor's first argument and is outside the bounded surface. Analysis
  classifies this as `unsupported` and the recipe abstains.

Files are pinned to LF (`.gitattributes`) so the content-addressed digests are
stable across platforms.
